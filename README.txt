PROMAPI WEBSITE — FRONT END TEMPLATE

Isi folder:
- index.html           Struktur halaman website
- css/style.css        Styling, warna, layout, dan responsive design
- js/script.js         Interaksi navigasi, tombol kembali ke atas, dan modal galeri
- assets/logo-promapi.png  Logo PROMAPI dari file yang diberikan

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder promapi-website.
3. Klik dua kali index.html atau jalankan menggunakan Live Server di VS Code.
4. Pastikan koneksi internet tersedia untuk memuat Bootstrap 5.3.3, Bootstrap Icons, dan Google Fonts dari CDN.

Catatan penyesuaian:
- Konten contoh/lorem ipsum, nama pengurus, tanggal agenda, alamat, email, dan tautan sosial perlu diganti.
- Tombol Daftar saat ini membuka draft email (mailto). Hubungkan ke Google Form atau backend pendaftaran jika sudah tersedia.
- Berita dan agenda masih berupa konten statis. Untuk pengelolaan mandiri, tahap berikutnya dapat dibuatkan dashboard admin/CMS dan database.
- Galeri saat ini memakai placeholder warna; ganti background pada .gallery-one sampai .gallery-five di css/style.css dengan foto kegiatan.
- Logo telah dibuat transparan dari gambar logo yang diberikan. Jika tersedia file logo PNG/SVG transparan asli, sebaiknya gunakan file tersebut.
